## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone -b clean-main https://github.com/shivamdevwork2005-collab/Spring-Framework-Full-Coarse-With_code-And-Notes.git
```

### 2️⃣ Open the Project

Open the cloned folder in **IntelliJ IDEA** or your preferred Java IDE.

### 3️⃣ Configure Java and Maven

- Install a compatible JDK.
- Configure Maven and resolve project dependencies.
- Open the relevant lecture or project folder.
- Check each project's `pom.xml` for its Java and dependency requirements.

### 4️⃣ Run the Examples

Run the appropriate Java or Spring Boot application from your IDE, following the configuration required by that project.

---

## 🔐 Important: Configuration & Security

Some projects may require database settings, OAuth credentials, or other environment-specific configuration.

- Never commit real API keys, passwords, client secrets, or access tokens.
- Store sensitive credentials in environment variables or a local, untracked configuration file.
- Keep `target/`, build output, and local secret files out of Git.
